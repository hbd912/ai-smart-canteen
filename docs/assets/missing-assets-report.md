## 7. 已知限制

1. 视频素材本身带有平台水印（右下角），属于源素材内容，网页不会额外叠加任何水印或播放器控制条。
2. 001-1 / 002-1 为 2554×1440，转码后统一到 1920 宽，以兼顾清晰度与首屏加载速度。
3. 菜品示意图为程序绘制，视觉风格与动漫场景不同（更偏扁平插画），已在 UI 中明确标注为示意。
4. 真实菜品照片、经核实的配方与营养数据需要食堂提供后，通过管理员后台上传/更新。
